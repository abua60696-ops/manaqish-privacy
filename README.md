# manaqish-privacy

هذا المستودع يحتوي عدة مكوّنات لمطعم مناقيش دير الزور:

- **`index.html`** — صفحة سياسة الخصوصية المنشورة للتطبيق.
- **`manager.html`** — تطبيق إدارة الطلبات (Manager App) للاستخدام الداخلي.
- **`app/`** — تطبيق الزبائن (Progressive Web App) الجديد المبني بـ React + Vite + TypeScript + Firebase. راجع [`app/README.md`](./app/README.md) لشرح كامل خطوة بخطوة لإعداد Firebase وتشغيل التطبيق ونشره.
